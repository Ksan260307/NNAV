# 目的関数の是正 — 3つの「正直なところ」への回答

ネットナビに意味層を載せたあと、正直に書いた欠点が 3 つありました。

1. 組み立て生成 (plan) がほとんど採用されない
2. 意図分類の skill が 0.02〜0.06 しかない
3. 閉じた語彙（疑問詞・人称・指示詞）が 52 語ある

調べたところ、3 つとも**重みの調整の問題ではなく設計の誤り**でした。
この文書はその診断と、実装した解決、そして実測を残すものです。

---

## 1. 組み立て生成が採用されない

### 診断: 目的関数が「再現せよ」になっていた

再ランキングの流暢さは `mean log P(token | prev)` でした。オペレーターが実際に
言った文は、**その確率モデルを作った当の文**なので、定義上ほぼ最大値を取ります。

```
目的関数 = 学習データを再現せよ
    最適解 = 丸暗記の再生
```

`plan_bias` をいくら積んでも、これは埋め合わせであって解決ではありません。
測り方そのものが記憶に有利でした。

### 解決: leave-one-out 流暢さ

理解度の測定で使っている prequential の考え方を、採点にも持ち込みました。
**その候補の出どころになった発話を、一度聞かなかったことにしてから採点する。**

```python
drop = w_operator * (synapse_decay ** 経過ターン) * discount
for (a, b) in 候補の隣接ペア:
    if (a, b) が出どころの発話にも含まれる:
        count[a][b] -= drop ;  tot[a] -= drop
```

引くのは **1 回分だけ**であることが肝心です。全出現を引くと、何度も聞いた
言い回しまで捨ててしまい、成体が急に不器用になります。

| | 引く前 | 引いた後 | 落ち幅 |
|---|---:|---:|---:|
| 一度きり聞いた文 | -1.32 | -2.67 | **-1.35** |
| 何度も聞いた「おはよう。」 | — | — | **-0.27** |

丸暗記だけが崩れ、身についた言い回しは残ります。

### 解決: 新しさの報酬に門番を付ける

```
novelty_bonus = novelty_weight   ただし  候補が新規 かつ 格フレームを破っていない
```

「新しく、**かつ**壊れていない」ときだけ報酬。破綻した新しさには 1 点も入りません。
組み立て生成は破綻率 0% なので、構造的にここを常に通ります。

### 段階との結合

`plan_bias` という恣意的な下駄は**削除**し、代わりに LOO の割引率と新しさの重みを
段階に結び付けました。

| 段階 | LOO 割引 | 新しさ | 意味 |
|---|---:|---:|---|
| EGG / LARVA | 0.0 | 0.0 | 子どもは覚えた文をそのまま言ってよい |
| CHILD | 0.3 | 0.3 | |
| TEEN | 0.6 | 0.7 | |
| ADULT | 1.0 | 1.0 | 大人は「言われたから言える」では通らない |
| NAVI | 1.0 | 1.2 | |

### 実測

同じ脳・同じ入力で、段階だけを変えた比較です。

```
TEEN    LOO0.6 新しさ0.7   新規発話率 31%   mimic-exact:49%
ADULT   LOO1.0 新しさ1.0   新規発話率 70%   mimic-exact:22%
NAVI    LOO1.0 新しさ1.2   新規発話率 89%   mimic-exact: 8%
```

**新規発話率**（オペレーターが一度も言っていない文を口にした割合）を新しい主指標に
し、ADULT 以上の成長ゲートにも入れました。思い出すだけの個体は大人になれません。

この変更だけで、組み立て生成の採用率は 0% → 8% になりました（900 ターンの通し）。
それでも低いのは、覚えた文をそのまま返すほうが流暢さで勝つ場面が実際に多いからで、
**記憶にない話題のときに出る**のが正しい姿だと考えています。

## 2. 意図の skill が低い

### 診断: 教師信号を取り違えていた

コードを読み返すと、学習していたのは

```python
observe_pair(last_intent, cur)   # 両方ともオペレーターの発話
```

つまり `P(オペレーターの次の発話の意図 | 前の発話の意図)` — **独話の中の話題転換**
であって、「問いかけにどう返すべきか」ではありませんでした。独話の意図遷移は
ほぼ一様なので、精度がベースラインに張り付くのは当然です。

クラスタリングは正しく働いていた（問いかけと平叙は分離できていた）のに、その上に
載せたモデルが間違った量を推定していました。

### 解決: オペレーターの反応を報酬にする

本当の教師信号は、ナビが返した**後に**オペレーターが取る行動です。

| 観測 | 報酬 |
|---|---:|
| `/good` | +2.0 |
| `/bad` | -2.0 |
| 直前の問いかけをほぼ言い直した（＝答えになっていなかった） | -1.0 |
| 返答の内容語を引き継いで続けた（＝会話が転がった） | +1.0 |
| 話題がまるごと切り替わった | -0.3 |

これを `reward[入力意図][返答意図]` に貯め、生成時は UCB で返し方を選びます
（試していない返し方には楽観的な下駄が付くので、探索は自然に起きます）。

理解度の意図軸も「次の意図を当てられたか」（独話モデルの精度）から
**返し方の適切さ**（平均報酬の正規化値）に差し替えました。

### 実測

```
以前  skill 0.02〜0.06    (独話の遷移予測。ほぼベースライン)
以後  適切さ 0.63         (199回の反応 / 平均報酬 +0.26)
```

副産物として、`/good` `/bad` が発話単位の強化だけでなく**返し方の方針の学習**にも
効くようになりました。

## 3. 閉じた語彙 52 語

### まず前提

この批判は、**すでに Janome の IPADIC に 30 万語の見出しを借りている**という事実の
前では小さいものです。この作品の原則は「語彙ゼロ」ではなく、正確には

> 何を意味するか・何を言うべきかは教わらない。
> 日本語がどういう形をしているかだけ借りる。

です。とはいえ消せるなら消したほうが強いので、**3 つとも分布から発見できるか**を
実装し、種を外して測りました。

### 手がかり

代名詞は 3 種類しかありません（人称・疑問詞・指示詞）。だから 2 つの比で三分割できます。

| 語 | 所有者率<br>「AのB」のA に立つ | 穴が埋まる率<br>後から別の値が入る |
|---|---:|---:|
| ぼく | 0.41 | 0.00 |
| きみ | 0.53 | 0.00 |
| 何 | 0.00 | 0.13 |
| それ | 0.00 | 0.00 |
| これ | 0.00 | 0.00 |

* **人称** = 所有者に立つ（「ぼくの名前」とは言うが「それの名前」とは言わない）
* **疑問詞** = 問いかけに偏り、しかも**そのスロットが後から別の値で埋まる**
  （「名前は何？」→「名前はロックマン」＝ 何 は値ではなく穴だった）
* **指示詞** = そのどちらでもない代名詞

人称の一人称／二人称の区別は、**同じ発話に一緒に出た代名詞は別の実体**という
制約でグラフを作って 2 彩色し、問いかけに多く出るほうを聞き手としました。

### 実測: 種を完全に外して 2000 ターン

```bash
python tools/rediscover.py --turns 2000
```

```
turn   200  疑問詞 0/8  一人称 1/2  二人称 1/1  指示詞 3/5(誤1)
turn   800  疑問詞 4/8  一人称 1/2  二人称 1/1  指示詞 5/6(誤1)
turn  2000  疑問詞 5/8  一人称 1/2  二人称 1/1  指示詞 5/6(誤1)

疑問詞: だれ どうして どこ なに なんで     誤検出: そう
一人称: ぼく        (「自分」は見つからず)
二人称: きみ
指示詞: あれ ここ これ そこ それ           誤検出: どっち
```

**耳にした 17 語のうち 12 語を自力で再発見、誤検出 2**。
分母は「ナビが一度でも聞いた語」に限っています（聞いていない語は見つけようがない）。

誤検出の内訳も示唆的です。`なんで` は正しく疑問詞なのに**種のリストのほうが
漏らしていました**（追加しました）。`どっち` を指示詞に入れてしまうのは、
`きみはどっちが好きかな。` のように `？` が付かない問いかけだと
疑問詞と見分けられないためです。

種は既定で有効のままにし、`bootstrap_function_words: false` で外せるようにしました。
「消せます」と主張するより、消して測れるようにしたほうが誠実だと考えています。

## 残る限界

* **組み立て生成の採用率は依然として低い**。再ランキングの目的関数が
  「オペレーターらしさ」である限り、記憶が有利な場面は残ります。
  LOO でその不当な有利さは消しましたが、正当な有利さ（本当に言い慣れている）は
  消していませんし、消すべきでもありません。
* **意図の報酬は雑音が多い**。「話題が切り替わった」を -0.3 と見なすのは乱暴で、
  オペレーターが単に別の話をしたいだけのこともあります。
* **機能語の再発見は完全ではない**。特に `？` が付かない問いかけは
  疑問詞の検出を難しくします。文末の上昇調は文字には残りません。
* **IPADIC への依存は消えません**。形態素解析器を自作しない限り無理ですし、
  そこは借りてよい線だと考えています（形は借りる、意味は借りない）。
